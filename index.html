Flappy Bird, Built from Discrete Electrical Components

NO MICROCONTROLLER · NO SOFTWARE
  • Engineered position-tracking logic for the bird and pipes using several cascaded 4-bit binary counters to represent x/y coordinates, replacing what would typically be software-based coordinate tracking.
  • Designed game logic, including scoring and collision detection, using logic gates, clock circuits, operational amplifiers, and 4-to-16 line decoders, with several feedback loops to simulate gravity and flying physics.
  • Developing the full circuit in KiCad, integrating discrete logic with an 8x8 LED matrix as the display for the video game.
